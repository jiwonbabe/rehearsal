# Meta evidence, channel reasoning, Korean — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ground every direction in the brand's own Meta data and sourced public statistics, add a per-channel verdict card, and make the whole site switchable to Korean (default English).

**Architecture:** `data/meta_mock.py` writes Graph-API-shaped mock JSON; `engine.RunEvidence` (Go + Python + fixture) turns it into evidence numbers; Spark role 7 (`prompts/channels.md`) reasons over evidence + stats and is validated so quoted numbers exist; Spark role 8 translates each cache file to Korean once; the server exposes connect/evidence/i18n; the web gets a Channels card, a connect button, reach + creator lists, and an EN/KO toggle.

**Tech Stack:** Go 1.22 stdlib, Python 3, vanilla JS.

**Spec:** `docs/superpowers/specs/2026-11-03-meta-evidence-design.md`

## Global Constraints

- Same as `docs/superpowers/plans/2026-11-03-launch.md` Global Constraints (stdlib, gofmt/vet/test, engine numbers only, no `time.Now`, oracle isolation, fixtures regenerated by script, banned words in `web/` incl. Korean "예측", badge on every page, server cache-only, commit per task with the Co-Authored-By line).
- Public statistics rows must carry `source`, `url`, `year`; `why_data` numbers must be in evidence ∪ stats.

## Review Focus

1. Mock data missing (handle unknown): `/api/meta/connect` returns 404 and the Directions page still renders without the Channels card.
2. Evidence with zero feed posts: `reach_vs_feed` must not divide by zero (feed avg 0 → ratio 0).
3. Spark `why_data` quoting a number not in evidence: the channel entry's `why_data` becomes "" (test `TestValidateChannels`).
4. Korean map missing a string: `tx()` falls back to English; page never shows "undefined".
5. Translation JSON with a changed shape: `ValidateTranslation` keeps English for that key.
